# 任务创建与模板改版待实现

目前“创建任务”入口只保留“编排任务”和“任务模板”两个核心功能。模板导入、手动填写、文件导入和语音输入共用编排表，已有模板可先回填成可编辑任务，再修改内容或使用日期；也可以在模板列表中选中模板，直接为任务页当前日期创建任务。编排范围支持指定日期，或选择星期后应用到本周、下周及自定义周期。一份模板可以关联多个星期，并同步到设置中的“每日计划生成”。

文件预填入口与现有 xlsx、xls、csv、tsv 解析仍予保留，但后续需要重新明确支持格式和核对流程。已有普通模板、星期模板和历史任务数据结构保持兼容。

## 导入文件

- 支持拖入文件，并让导入结果在写入前提供更完整的日期范围、冲突检查与调整界面。
- 识别多天且每天不同的内容并直接拆分写入；当前任务表仍以单日或相同多日安排为主。
- 将课表、循环安排文件直接创建为可复用的周期模板，并完成旧课表数据的迁移路径。

## 完整周期模板

- 当前已支持一份日模板关联多个星期；这里仅指每天内容彼此不同的完整二维周期模板。
- 定义数据结构：周期长度、周期中每一天的不同安排、起始锚点和模板类型。
- 对导入文件中的不同日期内容识别周期，并允许用户核对或调整周期长度。
- 复用时选择目标起始日期，根据周期展开任务；需明确覆盖、合并与冲突时的处理方式。
- 在模板列表中展示周期信息和每一天的内容预览，并补充编辑与删除测试。

## 验证

- 为多日文件识别、模板迁移、周期展开、时间冲突和取消操作补充自动化测试。
- 完成单日模板、周期模板、课表文件和普通安排文件的端到端验收。
