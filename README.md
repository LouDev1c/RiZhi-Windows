## 关于日织

日织用于安排每天的任务、快速确认完成情况、记录每日生活，并通过自然日、周、月、季度和年度统计观察计划时间的分配。

任务、记录、标签、模板和附件默认保存在本机。除检查 GitHub Releases 更新、首次下载离线语音模型以及同一局域网内的手机附件上传外，日常使用不需要把个人记录发送到外部服务。

## 核心能力

| 模块 | 能力 |
| --- | --- |
| 每日安排 | 创建单日或多日任务、导入课表、复用安排模板，并通过冲突提示维护清晰的时间线。 |
| 生活记录 | 记录每天发生的事，以多个自定义标签组织日子，并归档照片、动态图片和视频。 |
| 周期回顾 | 按日、周、月、季度或年度查看任务完成情况，以及各类任务的计划时间分配。 |
| 本地语音 | 使用离线模型完成任务与记录的语音转写，识别过程不依赖在线服务。 |
| 本地数据 | 任务、记录、设置和附件由用户掌控，可统一迁移存放位置，也可按日期删除。 |

## 安装与更新

1. 前往 [GitHub Releases](https://github.com/LouDev1c/rizhi-pc/releases)。
2. 打开标记为 **Latest** 的版本，下载安装程序并按提示完成安装。
3. 发布新版本后，旧版本启动时会询问是否更新。选择更新会下载并安装新版本，不会清理已有的本地数据。

正常卸载软件时，卸载程序会询问是否同时删除个人数据；自动更新不会弹出该询问。

## 使用教程

- 首次启动时可以选择查看使用教程，也可以随时点击右上角的“使用教程”重新打开。
- 教程会依次介绍任务创建、安排模板、完成情况与备注、生活记录、语音输入、附件归档、记录筛选、周期统计、数据管理、任务分类、标签和定位按钮。
- 教程中的“退出教程”按钮在任意步骤都可使用；中途退出后会返回打开教程前的页面。

## 任务

- 按日期查看当天安排，日期框旁的上下按钮用于切换前一天和后一天。
- 底部 `+` 用于新增空白任务。每项任务包含时间段、任务名称、任务分类和一行事前计划。
- 点击任务条的开始或结束时间会打开时间选择器。小时和分钟可分别键盘输入，也可使用上下方向键、鼠标滚轮或界面按钮调整。
- 时间段重叠时，所有冲突任务都会标红；前一项结束时间与后一项开始时间相同不算冲突。
- 跨日任务会按 `00:00` 拆分到对应日期，并保留任务分类、名称、事前计划和备注。
- 每个任务条右侧可直接选择“完成、部分完成、未完成”；未选择时显示“完成情况”。铅笔按钮用于添加可选备注，不要求每项任务都写反思。
- 拖动按钮用于调整任务顺序。删除任务后可使用 `Ctrl+Z` 撤销、`Ctrl+Y` 重做。
- “保存为模板”会保存当前日期的时间段、任务名称和任务分类，不包含事前计划、备注及完成情况。模板列表支持展开查看和逐条删除。

### 批量创建任务

“批量创建任务”提供两类入口：

- **课表**：手动填写学期课表，或导入 `xlsx`、`xls`、`csv`、`tsv` 课表文件。导入结果会先进入可编辑表格，确认后才写入任务。PDF 课表暂不支持导入。
- **每日安排**：复用已有安排模板，或为单日、连续多日创建任务。开始和结束时间分开填写，每格输入四位数字（如 `0930`）；方向键可在表格单元格间移动。底部 `+` 可增加条目，每行都可单独删除。

“语音创建任务”只负责录音、转写和解析。解析结果会以逐行纯文本显示，点击“确定”后回填到上一层“创建任务”表格，最终仍需在表格中确认安排。

## 记录

- “每日生活记录”按日期保存当天发生的事、状态和整体复盘。正文过长时仅编辑框内部滚动。
- 一天可以选择零个、一个或多个自定义标签作为“日子印记”。
- 切换页面或修改记录日期时，如果存在未保存内容，软件会询问“保存、不保存、取消”。
- 本地语音识别会把文本逐段插入编辑框，识别后仍需点击“保存记录”。
- “上传照片”会创建局域网上传页面。电脑与手机处于同一 Wi-Fi 或局域网时，可扫码上传照片、动态图片和视频，确认后归档到当前记录日期。
- “记录列表”提供“全部、日期、标签”三种明确的筛选方式；标签支持多选，并显示同时包含全部所选标签的记录。
- 文字搜索可以和日期或标签条件组合使用。点击记录条可查看生活记录、已确认的任务完成情况、任务备注及归档附件。

## 统计

“统计”页按自然日、自然周、自然月、自然季度或自然年回顾安排。参考筛选器会随周期切换：每日选择具体日期，每周只选择周一，每月选择年月，每季度选择年份与季度，每年只选择年份：

- 概览有安排的日期数，以及完成、部分完成、未完成和未确认的任务数；
- 饼状图按当前自定义任务分类展示所选周期中的计划时间占比，已停用但仍有历史任务的分类也会保留；
- 右侧条形图展示每天或每月的计划时间分布。

统计页中的时长均来自任务安排，表示计划时间，不代表实际投入时间。日子印记的查看与多标签筛选统一放在“记录列表”中。

## 设置

- **数据文件**：查看统一存放位置，以及月度数据、设置、照片和视频、离线语音模型的实际路径。更改统一存放位置时，会迁移其中的内容并尽量清理旧位置，同时保持原有目录结构。
- **数据删除**：按单日或日期范围选择性删除任务、生活记录和附件，也可以重置全部本地内容。删除前会再次确认。
- **任务分类**：新增、改名、换色、排序或停用任务分类。每个分类可单独启用专注与休息周期，默认分别为 50 分钟和 10 分钟，也可以自行修改。删除已使用的分类前，需先选择另一个分类接收历史任务和模板项。
- **标签**：新增、删除或编辑日子印记的颜色、简称和完整说明。
- **语音识别测试**：下载或检查离线模型，选择麦克风，并测试输入波形和本地识别结果。

## 浮动任务与托盘

- 浮动任务窗口显示当前任务、时间段、剩余时间和事前计划或备注，可切换置顶状态。
- 浮动窗口可以拖动；靠近屏幕边缘时会收起，点击边缘标签可再次展开，双击可打开主窗口。
- 未启用周期的分类只显示任务剩余时间；启用周期的分类会按该分类设置显示专注与休息倒计时。
- 关闭主窗口时可以选择退出软件，或最小化到系统托盘继续运行。
- 左下角定位按钮会返回任务页并定位到当前正在进行的安排。

## 离线语音识别

日织使用本地离线语音模型完成记录和任务的语音识别：

- 首次使用需要联网下载约 840 MB 的模型文件；
- 从语音创建页面触发下载后，该页面会提示模型正在下载，具体进度可在设置页标题旁查看；
- 下载完成后，录音识别在本机进行；
- “设置 → 语音识别测试”可查看模型状态、测试麦克风和识别效果；
- 更改统一存放位置时，已安装模型会随其他日织内容迁移。

## 本地存储

任务和记录按月保存为 JSON 文件。默认统一存放位置位于当前 Windows 用户的数据目录：

```text
C:\Users\用户\AppData\Roaming\rizhi\memory\
├─ rizhi-data-YYYY-MM.json
├─ rizhi-settings.json
├─ images\
└─ models\asr\
```

- `rizhi-data-YYYY-MM.json`：保存对应月份的任务安排和每日记录。
- `rizhi-settings.json`：保存任务分类及其周期、日子标签、安排模板和其他本地配置。
- `images`：按月份和日期保存记录中归档的照片与视频。
- `models\asr`：保存已安装的离线语音模型。

实际路径以“设置 → 数据文件”显示的内容为准。更改统一存放位置可用于迁移、备份或归档全部日织内容。

## 开发

```bash
npm install
npm start
```

检查主进程、渲染进程、解析器、存储模块及现有测试：

```bash
npm run check
```

打包命令：

```bash
npm run pack
npm run dist
```
